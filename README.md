# DataLineage-AI

DevPulse is a developer project health dashboard.

## Goal

Allow a developer to enter a project name and receive
a simulated project health report.

## Features

- Project name input
- Project health score
- Git statistics
- Pull request statistics
- Dependency information
- Environment information
- Backend REST API
- Frontend dashboard

## Future AI Feature

Later, an LLM will analyze the project data and generate
intelligent recommendations.
